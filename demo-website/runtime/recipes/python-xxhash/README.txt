python-xxhash4.0.1 built locally for CPython3.13.1, Emscripten4.0.9.
Uses the unmodified PyPI source distribution pinned by SHA256 in recipe.yaml.
Bundles the upstream xxHash C implementation, avoiding a separate dynamically
loaded libxxhash. Build uses emscripten-forge compiler and cross-python packages.
The resulting extension is a WASM side module with dylink.0 as first section.

Run build-package.sh with rattler-build0.67.0 on PATH, or set RATTLER_BUILD.
Canonical target variant configuration is variant.yaml beside the recipe.
Compiler flags are recorded in build.sh. Outputs go under runtime/build.
